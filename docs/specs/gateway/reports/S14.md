## Files created

**Control plane (`lib/control/`):**
- `tags.mjs` — generic `(resource_type, resource_id)` tags: `getTags`/`putTags`/`deleteTags`, `parseTagFilters`, AWS key rules (≤50/resource, 1–128 key charset `[\p{L}\p{Z}\p{N}_.:/=+\-@]`, value ≤256, `aws:`/`pods:` reserved, unicode allowed).
- `access-tokens.mjs` — `createToken`/`listTokens`/`revokeToken`/`resolveToken`, `matchesScope` (`*`/exact/`prefix*`), `expandHeldScopes` (catalog-backed creator check), `hashToken`. Personal tokens require expiry ≤ 1 y; service tokens cannot exceed the creator's held scopes; values (32 base62 bytes) shown once, sha256 stored.
- `rate-limit.mjs` — `checkIdempotency`/`recordIdempotency`/`hashBody` (24 h, same-key-different-body → 422) and `ControlRateLimiter` (10 rps sustained, burst 40 per project, `Retry-After`; heavy buckets: deployments 1/2 s per API, domain create 1/30 s, import 1/3 s) + `sharedLimiter` test hook.
- `stacks.mjs` — `planStack`/`applyStack`/`driftStack`, `hashStackFile`, `registerStackHandler`, built-in `api` kind (name identity, field-level diffs, prune-gated deletes, secret values rejected in-file).
- `event-subscriptions.mjs` — `create/list/deleteSubscription`, `fanOut` (audit-action match), `attemptDelivery` (HMAC `x-pods-signature`, backoff, 24 h budget, delivery log), `signEventBody`.

## Deviations from the spec or AWS, with reasons

1. **Stack kinds start at `api` only.** Usage plans, domains, WAF, portals belong to specs landing in parallel/after; the registry (`registerStackHandler`) is the extension point, and plan/apply/drift are kind-agnostic. No scope was invented for other specs' tables.
2. **`?tag:Key=Value` list filters not added to existing list endpoints.** The parser (`parseTagFilters`) ships, but wiring it into every in-flight list handler would collide with S08/S10 edits; recorded as a follow-up.
3. **Admin screens standalone** (not registered in `registry.jsx`/sidebar): parallel specs own those shared files right now.
4. **CLI stubs for S08/S10/S11/S12/S13 commands** return explicit "not implemented in this build yet" errors with exit 1 rather than guessing those specs' APIs.
