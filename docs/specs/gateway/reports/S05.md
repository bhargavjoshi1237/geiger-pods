## Deviations from the spec or AWS, with reasons

1. **Artifact `matcher` is JSON-safe, not a live trie.** The spec says “precompiled trie from S03”; the REST trie contains `Map`s and is not JSON-serializable. The artifact stores `matcher.http/rest` raw lists + engine-compatible `httpRoutes/restResources/restMethods`; the `match` phase compiles once per artifact (WeakMap, microseconds). Same determinism, deployable bytes.
2. **Deploy rate limit is 429, not 409.** Concurrent deploys → 409 `deploy_in_progress` (spec). The 1/2 s rate limit returns 429 `deploy_rate_limited` (spec implies 409 for concurrency only; 429 is the correct code for rate limits and matches the management-API error shape).
3. **In-process lock, not Postgres advisory lock by default.** The service takes `db.advisoryLock(apiId)` when the port offers it and always takes the in-process lock. Single-process tests and the Next server are correct; multi-instance deploys need the Postgres lock wired (one small `supabase-db.mjs` addition, S02-owned, left for the merge).
4. **`invoke` returns the backend response directly.** Until S06 wires `integrationResponse`/`methodResponse`, proxy/MOCK results are returned by `invoke` itself. S06 will move rendering downstream; the `ctx.integrationResult` is still set for it.
5. **HTTP `$default` appends the full path.** `maybeAppendDefaultPath` (S04) is honored, so `$default` with URI `/echo` serves `/echo/items` for `/items`. This is AWS parity; the test asserts it.
6. **Stage variables are validated at the control plane and substituted at invoke time** via the existing S04 `renderIntegrationUri`. Empty values render as empty strings.
7. **Custom domains (S11) fall through** in the loader (host pattern → path-based). No behavior invented for S11.
