## Deviations from AWS / the spec, with reasons

1. **SigV4 covers the full request URL (F46).** The host strips
   `/{api}/{stage}` before matching, but verification uses the client-sent URL
   (`ctx.originalUrl`). This *is* AWS parity (sign what you send); the prior
   behavior (verify stripped path) false-rejected every correctly-signed
   gateway request.
2. **Connector ingress via verified token headers, not a separate listener.**
   `x-pods-connector-id` + `x-pods-connector-token` verified through
   `ports.connectorIngress` (production: service-role token-hash lookup;
   revoked/mismatched fail) sets `viaConnector`/`viaSourceVpc`. Works behind
   the existing LB/TLS termination with no new ports; the hub tunnel path is
   unchanged for agent traffic.
3. **Loopback literals accepted at OpenAPI import (F41).** Non-loopback
   blocked literals (metadata, RFC1918, link-local, …) are 422 at import;
   loopback stays a runtime decision, mirroring `createIntegration` (dev
   fixtures such as S13's `http://127.0.0.1/x` keep importing; F4 + runtime
   guard enforce in prod).
4. **Domain policies govern network ingress (F34).** Associations +
   domain-policy evaluated pre-auth with connector facts (fail closed);
   user-Principal statements are *not* matched post-auth — the API resource
   policy owns user authorization. Documented residual, not silent.
5. **Slowloris guard is application-level.** Node 24's `headersTimeout` does
   not reap pure header stalls (verified empirically); the host arms its own
   per-socket timer (408 + destroy), cleared on request/upgrade so streams
   and WebSocket connections are unaffected.
6. **Named-group ReDoS residual (F49).** `(?<name>…)` passes the lookaround
   detector; 512-char + 100 KB caps bound the exposure. A strict linear
   engine is part-2 work.
7. **No migrations, no parity-status changes.** Hardening needed no schema
   changes; parity rows move only with the part-2 limits/bench/report work.
