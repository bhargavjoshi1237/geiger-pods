## Deviations from the spec or AWS, with reasons

1. **`basepath=split` treated as `prepend` + warning.** Pods has no
   multi-base import; one API is produced with the base path prepended.
2. **Unmapped `VPC_LINK` imports as `CONNECTOR` with null target +
   warning.** The draft then fails deploy (`missing_connector`) until
   the user maps a connector — honest, and the warning names the
   connection id.
3. **Draft export serializes Postman as unavailable** (`postman` is a
   stage-export extension; draft uses OAS). The spec lists postman
   under stage export; draft keeps OAS only.
4. **Export returns a JSON envelope** (`{format, contentType,
   extensions, document}`) instead of raw YAML bytes, because the
   management API is JSON (`route()` wrapper). The CLI `--out` writes
   the raw document; the Export dialog downloads it as a file.
5. **`operationName` added to compiled artifacts.** Needed so exports
   recover operationIds; additive, digest-affecting only for new
   deploys.
6. **No `docs` stack kind.** The spec calls for none (F25 tracks
   portals); docs travel with API clone instead.

   cache key makes regeneration idempotent; a `pods.sdk_jobs` table is the

3. **No `proxy.js` custom-domain rewrite.** Public portals serve

6. **Analytics stored, chart UI minimal.** `portal_events` counts page

### Deviations from AWS

1. **MCP transport is POST-only JSON.** The MCP Streamable-HTTP GET/SSE
   stream is not served; agents POST JSON-RPC and get a JSON reply (the
   engine's `handleMcpRequest` contract). Documented, not silent.
2. **`/_mcp` shadows greedy REST resources when enabled.** With agent tools
   enabled, `/{stage}/_mcp` always serves MCP even if a `/{proxy+}` resource
   would match; when disabled it 404s. The task mandates endpoint-only-when-
   enabled; AWS has no equivalent path to conflict with.
3. **Portal 403 renders with HTTP 200.** `forbidden()`/`unauthorized()`
   need the experimental `authInterrupts` flag (not enabled repo-wide), so
   anonymous sees a sign-in prompt and disallowed domains see a denied page
   (both snapshot-free) while only missing/disabled portals return a real
   404 via `notFound()`.
4. **`docsByLocation` is empty at the gateway edge.** `tools/call`
   descriptions come from the artifact path; per-stage documentation-version
   text is a control-plane render concern and does not affect calls.
