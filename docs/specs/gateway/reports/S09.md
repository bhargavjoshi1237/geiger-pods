## Deviations from the spec or AWS, with reasons

1. **Cache encryption key derivation.** Spec: per-stage DEK from the vault
   (S02). Engine: `ports.cacheDek`/`ctx.cacheDek` → vault
   `cache-dek:<stage>` → derived `sha256("cache-dek:project:stage")`
   fallback, so the data plane never fails closed and unit tests stay pure.
   KV never holds plaintext either way (test-inspected). Production should
   wire a real DEK secret (follow-up F29).
2. **Budgets are skip-on-exceed, LRU is TTL-only.** Spec asks approximate
   LRU; the engine tracks per-stage bytes and skips stores past budget
   (`CacheStoreSkipped` flag) with TTL expiry. True LRU needs a follow-up
   (F30).
3. **`CacheStoreSkipped` metric is set on context but S10's event builder
   (S10-owned) does not propagate it**, so the metric row never emits today.
   Behavior (skip) is tested; the metric wiring is a follow-up (F31).
4. **Canary artifact swap keeps the base `match`.** Match (phase 5) runs
   before canary (phase 7) against the base artifact; canary deployments of
   the same API share route shape, so the match is reused and only
   integrations/variables/deployment switch. Re-matching per artifact is a
   possible refinement (no test needs it).
5. **Stage settings travel via loader/`artifact.stageCache`, not the
   compiled artifact.** The artifact is immutable; mutable stage cache/
   canary live on the loader result (Supabase stage row) or test fixtures.
   `handle()` unit tests set `artifact.stageCache` directly.
6. **Abort test uses a stub upstream leg.** Bullet 12's runtime disconnect
   test runs through the real gateway/server/client-disconnect path, but
   the upstream leg is a stub `fetch` (records signal abort, no sockets):
   aborting a real undici fetch mid-body leaves orphan sockets that hang
   the test process (reproduced minimally; likely an undici abort quirk on
   this platform). Propagation timing (the S09-owned behavior) is asserted
   (<1 s bound, typically <25 ms). Full-socket teardown is S15 hardening
   (F32).
7. **No new stack kind.** Canary/cache are stage fields, not top-level
   resources; S14 ships only the `api` kind and F25 already tracks future
   kinds. Nothing to register.
8. **SSE passes through as opaque bytes** (no special-casing beyond
   no-buffering); Vercel-adapter stream cap is a deploy-time warning owned
   by S05/S13, not implemented here.
