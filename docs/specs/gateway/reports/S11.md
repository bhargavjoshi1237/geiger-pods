## Deviations from AWS, with reasons

1. **mTLS test double travels URL-encoded; the wire never carries a
   cert in a header.** Real handshakes use the TLS-layer side channel
   (`ctx.mtlsClientCert`). AWS passes `clientCertPem` URL-encoded in
   some contexts; we mirror that for the test header only.
2. **`execute-api:/*` resource shorthand.** AWS console policies use it;
   the evaluator expands it into the Pods ARN space (open
   region/account prefix). Full ARNs and `*` behave as in S07.
3. **CRL as serial list or PEM bundle** (Pods extension; AWS uses CRL
   files) — documented in `mtls.mjs`.
4. **Truststore referenced by PEM in the artifact** for tests; production
   loads issued/imported material via the service role (report §Files).
5. **EDGE acceptance is config-level** per the spec; infra
   (`docs/ops/edge.md`) is not provisioned.
6. **IP reputation lists out of scope** until a feed is chosen (spec).
