## Files created (S10-owned, pre-existing this pass)

**Engine (`lib/gateway/core/observe/`):**

- `event.mjs` — `buildRequestEvent` (§1 shape) + bounded in-memory sink
  (10 000 events, oldest dropped + `droppedEvents`, per-consumer
  isolation, off-response-path dispatch).
- `metrics.mjs` — per-protocol catalog (REST/HTTP/WS + Pods extras incl.
  `CacheStoreSkipped`), per-minute in-memory aggregation (counts, sums,
  64-bucket log-scale histograms 1 ms–60 s), `dimensionsFor` (incl.
  `{stage}/Canary` + detailed Resource/Method/Route dims),
  `reduceSeries` with p50/p90/p95/p99 from merged histograms.
- `access-log.mjs` — CLF/JSON/XML/CSV presets matching the AWS console
  strings, `$context.*` rendering, `requestId` requirement, 3 KB cap.
- `execution-log.mjs` — AWS-vocabulary phase lines in order, ERROR/INFO
  levels, `dataTraceEnabled` gating (1 KB truncation), always-on
  redaction (authorization, cookies, `x-api-key` to last 4, backend_auth
  values, resolved secrets → `****`).
- `tracing.mjs` — W3C + `X-Amzn-Trace-Id` conversion, forward to
  integrations, reservoir-1/s + 5% sampling (seeded), OTLP/HTTP JSON
  export, semantic span attributes.
- `sinks.mjs` — https (signed NDJSON ≤1 MB/5 s, retry/backoff 24 h) + s3
  (gzip objects `prefix/yyyy/mm/dd/HH/…`) + otlp_logs delivery.
- `alarm-eval.mjs` / `alarms.mjs` — CloudWatch M-out-of-N evaluation,
  `treat_missing_data` variants, exactly-once transition notifications
  (`alarmId:stateUpdatedAt` idempotency), history rows.
